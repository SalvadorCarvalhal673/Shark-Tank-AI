# Reading a financial outcome

After explicit acceptance, expand **How to read your deal** in the practice debrief. The guide explains the existing implied valuations and the difference between percentage-point and relative dilution. A move from 60% to 54% is six percentage points, or 10% of the original stake. The ownership values come from the existing primary-equity calculation. Values can appear unchanged due to rounding. A no-deal run creates no funding or ownership change.
